# Olympic Games Data Analysis Dashboard

## Project Overview

This project is an interactive Olympic Games Dashboard created using Power BI. The dashboard provides detailed insights into Olympic medal distributions, athlete participation, country-wise performance, sports analysis, and age-group statistics.

The main objective of this project is to analyze historical Olympic Games data and present meaningful insights through visual analytics and business intelligence techniques.

---

# Dashboard Features

The dashboard includes multiple interactive visualizations and filters to help users explore Olympic Games data efficiently.

### Key Highlights

* Total Medals Analysis
* Gold, Silver, and Bronze Medal Distribution
* Country-wise Medal Analysis
* Sport-wise Medal Analysis
* Athlete Participation Statistics
* Age Group Analysis
* Top Performing Athletes
* Interactive Filters and Slicers

# Dashboard Visualizations

## 1. World Map Visualization

Displays country-wise Olympic participation and medal distribution across the world.

### Insights:

* United States shows the highest medal count.
* European countries have strong Olympic participation.
* Multiple countries contribute across different sports categories.

---

## 2. Medal Distribution by Country

This visualization compares Gold, Silver, and Bronze medals among top-performing countries.

### Top Countries:

* United States
* Soviet Union
* Germany
* Italy

---

## 3. Sport-wise Medal Analysis

Shows which sports contributed the highest number of medals.

### Major Sports:

* Athletics
* Swimming
* Cycling
* Rowing
* Football

Athletics and Swimming have the highest medal counts.

---

## 4. Gold Medal Analysis

Analyzes Gold medal achievements by country and gender categories.

### Insights:

* United States dominates Gold medal counts.
* Male athletes contribute more medals in several countries.
* Strong competition among top Olympic nations.

---

## 5. Age Group Analysis

A donut chart visualization representing medal distribution based on athlete age groups.

### Insights:

* Most medal-winning athletes are between 20–35 years old.
* Peak performance age is around 26–30 years.

---

## 6. Top Athletes Table

Displays the top-performing Olympic athletes along with their country and total medal counts.

### Example Athletes:

* Michael Fred Phelps
* Nikolay Andrianov
* Takashi Ono
* Edoardo Mangiarotti
